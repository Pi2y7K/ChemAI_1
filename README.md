# ChemAI_1
Репозиторий содержит решение мини-задачи по извлечению текста  из научных статей лекций.
## Архитектура проекта
- `Source code in python` — Python-скрипт для интеллектуального анализа текстовых слоев документов и регулярного поиска.
- `database.csv` — Итоговая база данных со структурированными метаданными научных статей.
- `README.md` — Описание обработки данных и инструкция.

## Структура собираемой Базы Данных (`database.csv`)
1. **Article title** — Исходное имя статьи.
2. **Authors** — Авторы исходной научной статьи.
3. **DOI**
4. **Component ID** - код для компоненты
6. **Target Receptor** — таргетироавнный рецептор.
7. **Activity metric, Value nM, selectivity profile** - другие важные метрики, извлекаемые из исходных статей в папке с материалами лекций.

## Описание логики обработки (ETL-процесс)
1. **Извлечение (Extract)**: Постраничный обход документов с помощью пакета `pypdf`/`python-pptx` для формирования сплошного текстового массива.
2. **Трансформация (Transform)**: Применение нормализации текстовых строк и детекция ключевых маркеров (например, "Naltrexamine", "SMILES", "B3LYP", "InChI") для идентификации важнейший параметров.
3. **Загрузка (Load)**: Структурирование признаков в `pandas.DataFrame` и экспорт в CSV.
