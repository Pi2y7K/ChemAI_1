# ChemAI_1
Репозиторий содержит решение мини-задачи по извлечению текста  из научных статей и презентаций лекций.
## Архитектура проекта
- `process_pdfs.py` — Python-скрипт для интеллектуального анализа текстовых слоев документов и регулярного поиска сущностей.
- `database.csv` — Итоговая база данных (БД) со структурированными метаданными научных статей и лекций.
- `README.md` — Описание обработки данных и инструкция.

## Структура собираемой Базы Данных (`database.csv`)
1. **Filename** — Исходное имя файла из папки "Ai in CHEM".
2. **Title** — Валидированное научное название статьи или лекционной темы.
3. **Keywords** — Извлеченные ключевые химические термины (например, наименования рецепторов, лигандов, регуляторных систем).
4. **Methods** — Экстрагированные экспериментальные, расчетные или программные методы (Квантово-химические расчеты DFT, молекулярная динамика, Image-to-Structure парсеры вроде MolScribe/OSRA).
5. **Sample_Size** — Объекты исследования, выборки, шаблоны гомологии или клеточные линии.

## Описание логики обработки (ETL-процесс)
1. **Извлечение (Extract)**: Постраничный обход документов с помощью пакета `pypdf`/`python-pptx` для формирования сплошного текстового массива.
2. **Трансформация (Transform)**: Применение нормализации текстовых строк и детекция ключевых маркеров (например, "Naltrexamine", "SMILES", "B3LYP", "InChI") для идентификации типа документа, его методологического аппарата и дескрипторов.
3. **Загрузка (Load)**: Структурирование признаков в `pandas.DataFrame` и экспорт в CSV с кодировкой `utf-8-sig` для корректного парсинга кириллицы в Excel.
